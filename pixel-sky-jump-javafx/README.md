# Pixel Sky Jump - JavaFX

Juego 2D pixel-art inspirado en la imagen proporcionada.

## Requisitos
- JDK 21
- Maven 3.9+
- JavaFX 21 (Maven lo descarga automáticamente)

## Ejecutar
Desde esta carpeta:

```bash
mvn clean javafx:run
```

## Controles
- A / D o ← / →: mover
- ESPACIO / W / ↑: saltar
- ENTER: iniciar
- R: reiniciar después de Game Over

## Incluye
- Física de salto y gravedad
- Plataformas flotantes
- Monedas
- Enemigos
- 3 vidas
- Puntaje
- Pantalla de inicio
- Game Over y reinicio
- Estética pixel-art inspirada en la referencia
